# 🛒 Blinkit Dataset Analysis

## 📌 Project Overview

This project focuses on analyzing the **Blinkit Dataset** using **IBM Cognos** to generate meaningful business insights from order, product, quantity, and pricing data.

The project contains **9 business problem statements** covering order value, product performance, revenue contribution, average order value, order-size distribution, product frequency, high-value orders, price variation, and quantity-vs-price analysis.

---

## 🎯 Objectives

* Calculate the total value of each order.
* Identify top-selling products based on quantity.
* Analyze revenue contribution by product.
* Calculate Average Order Value (AOV).
* Categorize orders according to order size.
* Identify frequently occurring products.
* Find high-value orders above a specified threshold.
* Analyze price variation across products.
* Study the relationship between quantity purchased and unit price.

---

## 📊 Dataset

**Dataset:** Blinkit Dataset

### Main Fields Used

* `order_id`
* `product_id`
* `quantity`
* `unit_price`
* `product_name` *(where available)*

The project uses these fields to perform calculations, grouping, aggregation, and sorting.

# 🔍 Business Problems

## 1. Total Order Value Per Order

Calculate the total value of each order using:

```text
Order Value = Quantity × Unit Price
```

The calculated line value is aggregated by `order_id`.

---

## 2. Top-Selling Product by Quantity

Identify the product with the highest total quantity ordered across all orders.

### Method

1. Group by `product_id`.
2. Calculate total quantity.
3. Sort the result in descending order.

The first product represents the highest total quantity ordered.

---

## 3. Revenue Contribution per Product

Calculate the revenue generated by each product using:

```text
Revenue = Quantity × Unit Price
```

The revenue is then aggregated using **Total (Sum)** for each product.

---

## 4. Average Order Value

Calculate the average value of all orders.

First, the total revenue is calculated for each `order_id`, and then the average of the order totals is determined.

---

## 5. Order Size Distribution

Orders are categorized according to the total number of items purchased.

Example categories:

* Small
* Medium
* Large

The total quantity per order is calculated and then used to create an `OrderCategory`. The number of orders in each category is counted.

---

## 6. Most Frequent Product Per Order

Identify which `product_id` appears most frequently across orders.

### Method

1. Add `order_id` and `product_id`.
2. Calculate product frequency.
3. Group by `product_id`.
4. Sort the frequency in descending order.

The product with the highest frequency appears first.

---

## 7. High-Value Orders

Identify orders whose total order value exceeds a specified threshold, such as **₹5,000**.

The total order value is calculated and aggregated by `order_id`.

---

## 8. Price Variation Across Products

Find products with the **highest and lowest average unit prices**.

### Method

* Calculate `Avg_Unit_Price`.
* Group by `product_id`.
* Sort in descending order to find the highest average price.
* Sort in ascending order to find the lowest average price.

---

## 9. Quantity vs. Price Correlation

Analyze the relationship between **quantity purchased** and **unit price**.

This can help identify patterns such as:

* Higher quantities associated with different prices.
* Lower quantities associated with higher prices.
* Possible bulk-purchasing price patterns.

The analysis uses `product_id`, `quantity`, and `unit_price`, with grouping by quantity for comparison.
